# RASHEL Digital School: דף נחיתה לקמפיין חנוכה (WordPress)

תבנית וורדפרס ייעודית שמממשת את עיצוב ה-Handoff של דף הנחיתה "בואי להאיר את הכישרון שבך!": קורסים דיגיטליים בקולינריה ובעיצוב ב-50% הנחה. פותחה לפי [תקן הפיתוח והאבטחה של Multi Digital](docs/DEV-STANDARD.md), גרסה 1.1.

- **מטרה ראשית:** הגולשת בוחרת קורס ועוברת לעמוד התשלום שלו ב-Cardcom.
- **מטרה משנית:** טופס לידים לשיחת ייעוץ.
- **רמת סיכון:** 1 (אתר שיווקי וטופס לידים). אושרה על ידי הבעלים ב-23.11.2026.

## התקנה

1. לבנות את החבילה: `bash bin/build-zip.sh` (נוצר `dist/rashel-hanukkah.zip`), או להעלות את התיקייה `rashel-hanukkah` אל `wp-content/themes`.
2. בוורדפרס: עיצוב > ערכות עיצוב > הוספה > העלאת ערכה, ולהפעיל.
3. להגדיר את שפת האתר לעברית ואת אזור הזמן ל-Asia/Jerusalem (הגדרות > כללי). שעון הספירה סופר לפי אזור הזמן של האתר.
4. בהפעלה נוצרים אוטומטית 11 הקורסים ושלושת עמודי החובה (מדיניות פרטיות, תנאי שימוש, הצהרת נגישות). עמוד שכבר קיים באתר אינו נדרס.
5. דף הנחיתה מוצג בעמוד הבית. לאתר שעמוד הבית שלו אחר: ליצור עמוד ולבחור בתבנית העמוד "דף נחיתה חנוכה".

דרישות: WordPress 6.8 ומעלה, PHP 8.3 ומעלה. אין תלות בתוספים.

## ניהול האתר

הכול נערך מלוח הבקרה, בלי לגעת בקוד:

| איפה | מה |
| --- | --- |
| ראשל חנוכה > הגדרות | תאריך סיום המבצע, אחוז ההנחה, טלפון, הפס התחתון, סרגל הנגישות, הקרדיט, עמודי החובה, כתוביות לסרטונים |
| ראשל חנוכה > טקסטים | כל משפט בעמוד. שדה ריק חוזר לנוסח העיצוב. מילים בין `*כוכביות*` מקבלות את המרקר הצהוב |
| ראשל חנוכה > חיבורים ולידים | מייל להתראות, תקופת שמירת לידים, Webhook ל-CRM חיצוני, מפתחות Cloudflare Turnstile |
| ראשל חנוכה > יומן פעולות | מי שינה מה ומתי |
| קורסים | שם, קטגוריה, תווית, תיאור, מחיר מבצע, מחיר מקורי, קישור Cardcom, תמונה וסדר |
| לידים | כל הפניות מהטופס: סטטוס, הערות, ייצוא ל-CSV |

מפתחות סודיים (Turnstile, חתימת Webhook) נשמרים מוצפנים, אינם מוצגים שוב ואינם נשלחים לדפדפן. אפשר להגדיר אותם גם ב-`wp-config.php`, ואז השדה בלוח הבקרה ננעל:

```php
define( 'RSH_TURNSTILE_SITE_KEY', '...' );
define( 'RSH_TURNSTILE_SECRET_KEY', '...' );
define( 'RSH_WEBHOOK_SECRET', '...' );
define( 'RSH_KEY', '...' ); // לא חובה: מפתח הצפנה משלכם, 32 בתים ב-base64. בלעדיו המפתח נגזר מה-salts של האתר.
```

### Webhook ל-CRM חיצוני

כל ליד נשלח כ-JSON בבקשת POST (`id`, `name`, `phone`, `email`, `source`, `utm`, `received`). מפתח חתימה הוא חובה: בלי מפתח תקין שום ליד לא נשלח החוצה, והדשבורד מתריע על כך. כל בקשה כוללת את הכותרת `X-Rashel-Signature: t=<זמן>,v1=<HMAC-SHA256 של "זמן.גוף">`. כשל נשלח שוב עד ארבע פעמים, והליד נשמר באתר בכל מקרה.

## שינויים מהעיצוב שהתקן מחייב

העיצוב (גרסה 11) מומש אחד לאחד, והטקסטים מופיעים מילה במילה. הדברים הבאים נוספו או שונו כי התקן מחייב אותם, והנגישות והפרטיות גוברות על בקשת עיצוב (סעיף 1.3):

1. **ניגודיות 4.5:1 לטקסט קטן (8.4.1).** כפתורים ולשוניות עם טקסט לבן קטן צבועים בגוון מעט כהה יותר של הסגול (`#9d6471` במקום `#a86b79`). לארבעה מצבעי הקורסים יש גוון "חזק" לטקסט קטן, לכפתור ולכותרת הסילבוס (טורקיז `#437c8e`, אפור-חום `#82735a`, ורוד `#a8606e`, סגול `#9d6471`). תגית הקורס על התמונה כהה במקום לבן שקוף, התווית "סילבוס הקורס" לבנה במקום צהובה, והמחיר המחוק בגוון `#7a6d62`.
2. **שדות הטופס (8.6.1, 8.6.2).** לכל שדה תווית אמיתית שצפה מעל השדה במקום placeholder בלבד, ושדות חובה מסומנים "(חובה)".
3. **שאלות הפתיחה המתחלפות (8.5.5).** נוסף כפתור השהיה, ונקודות הניווט קיבלו שטח לחיצה של 24px. ההחלפה נעצרת גם במעבר עכבר ובפוקוס.
4. **הערת פרטיות** וקישור למדיניות מתחת לכפתור השליחה (5.2).
5. **פוטר:** נוספו קישורי עמודי החובה, "הגדרות פרטיות", שורת זכויות וקרדיט (15.4, 15.6).
6. **הפחתת תנועה ו-JavaScript כבוי (8.5.6, 14.1.2).** שלוש שאלות הפתיחה מוצגות זו מתחת לזו, שתי קטגוריות הקורסים מוצגות ברצף, הקונפטי והאנימציות כבויים, וכפתורים שאינם פועלים בלי JavaScript (לשוניות, סילבוס, חיצי הקרוסלה) אינם מוצגים.

**פער בתיק העיצוב:** ה-README של העיצוב מתאר את שאלות הפתיחה כמסך נעוץ שגולל לרוחב, אבל קובץ העיצוב עצמו (`Rashel-Landing.dc.html`) מחליף שאלה כל 5.2 שניות עם נקודות ניווט. מומש לפי הקובץ, שהוא מקור האמת.

## נכסים

- **פונטים:** Oscar (כותרות), Afek (טקסט) ו-Barlev (חתימה), מאוחסנים בתבנית. הרישיון שייך ללקוח.
- **תמונות:** כל התמונות הומרו ל-WebP ומאוחסנות בתבנית, כולל 11 תמונות הקורסים. אין טעינה מאתר אחר. תמונה שנבחרת לקורס בספריית המדיה מחליפה את תמונת ברירת המחדל.
- **סרטונים:** `v01.mp4` ו-`v02.mp4` קודדו מחדש (H.264, ‏480p, ‏faststart) מ-25MB ל-7.5MB יחד.
- **קוד קופון:** ברירת המחדל `H50`. משנים במסך "ראשל חנוכה"; שדה ריק מסיר את הקופון מהעמוד.
- **סילבוס:** לכל קורס שדה "סילבוס": שורה לכל שיעור בצורה `כותרת | תיאור`, ושורת בונוס מתחילה ב-`* `. עדכון מגרסה 1 ממלא את הסילבוס של הקורסים שהותקנו אוטומטית.

## פתוח מול הלקוח

- **יעד הטופס:** כרגע ליד נשמר באתר ונשלחת התראה למייל מנהל האתר. צריך כתובת מייל להתראות, ואם יש CRM, כתובת Webhook.
- **מחירים מקוריים:** מחושבים ממחיר המבצע לפי 50%. אפשר להזין מחיר מקורי לכל קורס.
- **מועד הסיום:** 13.12.2026 בשעה 23:59:59 שעון ישראל.
- **כתוביות לשני הסרטונים** (קובצי `.vtt`), ותמלול להמלצות אם רוצים.
- **נוסח משפטי:** שלושת עמודי החובה נוצרים כטיוטה ראשונה. צריך אישור יועץ משפטי, מדיניות ביטולים, ופרטי רכז הנגישות.
- **מפתחות Cloudflare Turnstile** לדומיין הסופי.

## באחריות האחסון, לא התבנית

HTTPS בלבד ו-HSTS, Cloudflare לפני האתר, Content-Security-Policy, הגבלת ניסיונות כניסה ו-MFA למנהלים, `DISALLOW_FILE_EDIT`, גיבוי יומי וניטור זמינות (סעיפים 4.9, 11, 15.7, 16.8). התבנית שולחת בעצמה `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy` ו-`Permissions-Policy`, מכבה XML-RPC וחוסמת חשיפת שמות משתמשים.
